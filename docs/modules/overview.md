# Modules

The drop-in modules of this repository; each name links its reference page. The scripts have pages too:
[daily audit](daily-audit.md) and [home seed](home-seed.md).

| Module                              | Files                                | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[Team](team.md)**                 | `team.ts`, `team-web/`               | Named agents in ordinary Pi Pocket sessions, a supervisor's delegation into their repositories, and each agent's own memory.                                                                                                                                                                                                                                                                                                                                                      |
| **[Homewiki](homewiki.md)**         | `homewiki.ts`, `homewiki-web/`       | The "Wiki" rail page: renders a Markdown wiki checkout (`README.md` and `docs/**/*.md`) live from disk, read-only and owner-only. Default folder `~/projects/homewiki`; set `PI_POCKET_HOMEWIKI_ROOT` for another one.                                                                                                                                                                                                                                                            |
| **[Night shift](night-shift.md)**   | `night-shift.ts`, `night-shift-web/` | `/night-shift`: Pi works on an objective in rounds while you sleep, until a stop condition in words (and an optional check command), a round limit, or a deadline; then it writes a summary for the morning.                                                                                                                                                                                                                                                                      |
| **[Model router](model-router.md)** | `model-router.ts`                    | _Shadow only_: classifies each delegation's brief with TypeSafe Jev, and records the model tier and model it would pick for the worker and the brief's features, on the desk thread. It never changes a model, a worker, or a thinking level.                                                                                                                                                                                                                                     |
| **[Desk](desk.md)**                 | `desk.ts`, `desk-web/`               | One thread for each piece of work the team runs in the background: opened by `team_delegate`, listed and read by a supervisor session, seeded once from a `seed.json` triage file, given its agents' reports, observed by a sweep that closes it when every part is closed, tied to the PRs in its repository, held to a cap, carrying the asks to Brian, shown on an owner-only page, copied to a git folder, woken by a dated check, and planned before it starts (parts 1–10). |
| **[Terminal](terminal.md)**         | `terminal.ts`, `terminal-web/`       | The "Terminal" rail page: an interactive login shell as the server's user, in a folder you pick, drawn by the vendored xterm.js. Output by 1 long poll for each tab (25 s at most), input and resize by small POSTs, the shell on a Python pty helper. Owner-only; keys go straight to the shell, where Lancet Guard and Pi do not see them.                                                                                                                                      |
| **[GitHub hooks](github-hooks.md)** | `github-hooks.ts`                    | A listener on port 8790 for signed GitHub webhook deliveries (`POST /github`, peers in `allowFrom` only): it keeps pattern-checked facts, no GitHub text, records them, and hands them to the desk's `nudge` for an early sync. `/github-hooks start` starts its receiver task once.                                                                                                                                                                                              |

Direction: every change here follows [docs/beacon.md](../beacon.md): collect as much as we can, analyze it in the daily audit, and act on the numbers to compare prompts, models and policies.
